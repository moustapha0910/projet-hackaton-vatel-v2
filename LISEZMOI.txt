IT Resto
========
Application de commande à table pour restaurants (PHP + JSON, sans base de données).

Démarrage rapide (XAMPP)
  1. Copiez le dossier du projet dans C:\xampp\htdocs\
  2. Lancez Apache depuis le panneau XAMPP.
  3. Ouvrez http://localhost/<nom-du-dossier>/

Toute la documentation (réglages, changement de nom, sommelier IA, notifications, démo, sécurité) est dans README.md.

Changer le nom du restaurant : admin.php -> Réglages -> Identité du restaurant.
Changer les mots de passe     : config.php -> ADMIN_PASSWORD et KITCHEN_PASSWORD (par défaut admin123 / cuisine123 : à changer).
